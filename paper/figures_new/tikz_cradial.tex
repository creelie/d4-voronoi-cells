% tikz_cradial.tex -- fig:radial, the counts of prop:radial: for M
% centres within sqrt 6 with T(Y) <= 8, the least number of centres within a radius rho, one panel
% per radius 2.05, 2.1, 2.15, 2.2.  Filled marks: proved by the case certificates (a count within a
% smaller radius also counts within a larger one).  Open marks: the caps alone, the least n
% with n S(2) + (M - n) S(rho) < tau impossible below it (ball arithmetic).
% Data: cradial_counts.dat, written by cradial_data.py from the check logs.
% Build:  pdflatex tikz_cradial.tex && pdftoppm -r 500 -png -singlefile tikz_cradial.pdf ../figures/fig_tikz_cradial
% Test:   python3 tikz_overlap_check.py tikz_cradial.tex
